# External review

Bernard Parisse provided the external review dated 2026-11-21 that informed
the benchmark reorientation. He co-created Giac/Xcas and maintains Xcas;
Giac is a system measured by this benchmark. This relationship is documented
on [his institutional page](https://www-fourier.univ-grenoble-alpes.fr/~parisse/english).

The review predates these implementation changes and should not be read as
approval of them. The public relationship stated here is context from the
cited source, not a declaration made on his behalf. Contributor declarations
are recorded separately in [`docs/disclosures.tsv`](disclosures.tsv).
